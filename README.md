# Visuals
## Interactive Mathematics & Simulation, Rendered in Real Time

Visuals is a browser-based interactive visualization platform that turns **mathematics, physics, and abstract logic** into dynamic, manipulable visuals.

Behind every curve, waveform, and diagram lies **explicit mathematical structure** — not animations for aesthetics, but **math made visible**.

This project exists at the intersection of **education, simulation, and visual computing**.

---

## What This Project Actually Is

Visuals is **not** a UI experiment.  
It is a **math engine rendered through the browser**.

The system performs real calculations in code and renders their behavior visually using the DOM and canvas.

---

## What It Visualizes (more coming)

- Electrical **AC circuit behavior**
- **Graph transformations** driven by equations
- **Data structure concepts**
- **Set theory and Venn logic**

All computations are performed explicitly in JavaScript before rendering.

---

## Features

### Circuit Visualization
- AC waveform simulation
- Parameter-driven behavior (frequency, phase, amplitude)
- Real mathematical relationships rendered visually

### Mathematical Graphing
- Real-time graph updates based on variable changes
- Interactive exploration of functions and transformations

### Data Structures (Visual Intuition)
- Visual representations of abstract data structures
- Designed to teach through motion and interaction

### Venn Diagrams & Set Logic
- Visual explanation of set operations
- Intuition-first approach to abstract logic

---

## The Math Behind It (Important)

This project hides **zero math**.

Depending on the module, Visuals uses:

- Trigonometric functions for waveform generation
- Discrete mathematical logic for diagrams
- Coordinate transformations for graph rendering
- Algorithmic state changes for data structure behavior

The goal is **not to simplify mathematics**.  
The goal is to **expose it through interaction**.

If you understand the visuals, you understand the math.
